## 二、详细说明（Markdown，整段粘贴）

```markdown
# FJMU 自动评教助手 v3

> ⚠️ **仅适用于福建医科大学评教系统**（`jxzhpt.webvpn.fjmu.edu.cn`），装到其他站点不会激活。

## 这是什么

针对福医大评教系统的重写版脚本。基于脚本 #5233《FJMU自动评教助手 v2.2》修复，
原版的跨页面循环失效、弹窗误点、选择器含非法 `:contains()` 等问题在本版全部重做。

## 与 v2.2 的核心差异

| 维度 | v2.2 | v3.1.1 |
|---|---|---|
| 跨课程流程 | 单页面 `while` 循环，跳转即失效 | 跨页面状态机（GM 存储 + 页面 token） |
| 点击 | 一次动作触发 3–5 个 click | 严格单击，弹窗最多点 1 次 |
| 题目数量 | 写死 5 题 | 遍历所有 `.rater_input`，自适应 |
| 满分来源 | 写死 30/20/20/15/15 | 从 `.fscore` / 题干 / 属性读取 |
| 弹窗选择器 | 含非法 `:contains()`，必抛异常 | 可见性 + 文本 + 浮层三重判定 |
| 失败处理 | 失败也当成功 | 失败计数 + 熔断，状态如实上报 |
| 页面改版 | 直接失效 | 多路兜底 + 「诊断」导出结构 |

另外适配了 2026-11 起的新版界面：**SPA + 右侧抽屉 + 同源 iframe**（顶层页面里一个输入框都没有，
表单在 `iframe[0]` 的 Vue 页面里），脚本会自动定位活动文档。

## 安装

1. 先装 [ScriptCat](https://scriptcat.org/) 或 Tampermonkey
2. 点本页的「安装脚本」
3. 打开评教系统，右上角出现「🎯 自动评教 v3.1.1」面板

> **如果你装过 v2.2（脚本 #5233），请先卸载它再装本脚本。**
> 两者都会操作同一个评教页面，同时启用会互相干扰。

## 使用

```
列表页 → 点「▶ 开始巡航」
        → 自动点第一个「去填写」
        → 跳转后自动填分
        → 提交 → 自动点「确定」
        → 回到列表继续下一门 …… 直到没有「去填写」按钮
```

**第一次用建议先关掉「自动提交」**，只让它填写，自己看一眼分数对不对再提交。

### 面板说明

| 控件 | 作用 |
|---|---|
| 第 1–5 题滑块 | 每题得分百分比，满分 30 的题设 90% = 27 分 |
| 自动提交 | 关掉后只填不交，提交自己点 |
| 总是填评语 | 勾上则每门课都写评语；不勾只在总分低于 70% 时写 |
| 安全延迟 | 每步加 0–400ms 随机延迟，行为更像真人 |
| 随机浮动 | 每门课分数重新生成，总分落在 (84,95)，单项不低于满分 60% |
| ▶ 开始巡航 | 清空计数重开，状态可跨页面保持 |
| ■ 停止 | 随时停，刷新页面后不会自己乱跑 |
| 填写当前页 | 只填当前表单，不提交 |
| 诊断 / 导出 | 把当前页元素结构摘要复制到剪贴板（页面改版时用） |

### 安全边界

- 单次最多处理 40 门，运行超过 25 分钟自动停
- 连续失败 3 次自动熔断
- 同一表单页提交后 2 分钟内不会重复提交

## 出问题怎么办

点面板上的「诊断 / 导出」，把复制的文本发到
[Issues](https://github.com/RevieNeal/fjmueval-userscript/issues)，日志带时间戳和中文报错，照着贴即可。
```
